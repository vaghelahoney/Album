# How to Create Your Static QR Code

Since you are deploying to a static URL (like Vercel), your QR Code doesn't need to change even if the content of the site updates.

## 1. Deploy Your App
First, deploy this project to Vercel (or Netlify).
Example URL: `https://sarah-and-james-wedding.vercel.app`

## 2. Generate the QR Code
Go to a free high-quality QR generator like [Adobe Express QR](https://www.adobe.com/express/feature/image/qr-code-generator) or [QRCode Monkey](https://www.qrcode-monkey.com/).

**Settings:**
*   **Content**: `https://sarah-and-james-wedding.vercel.app`
*   **Color**: Black (Standard) or Dark Gray (#333) for elegance.
*   **Logo**: You can add a small "Heart" icon in the center.
*   **Resolution**: High Quality (SVG or PNG 1000px).

## 3. Print
Place this QR code on:
*   Table cards
*   Welcome easel
*   Thank you notes
